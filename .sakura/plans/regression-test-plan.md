# 高风险回归测试计划

按业务风险排序实施，优先覆盖曾造成误罚、审核绕过或整条调用失败的路径。

## P0：审核正确性

### 协议脏数据

- 纯文字、纯回复、回复+文字、多层引用。
- 引用原文违规但用户附言正常：不得处罚用户。
- 加群问题含违禁词、答案正常：只审核答案。
- 提取失败时验证回退与日志，不得崩溃。

### 决策顺序与配置

- 通过词同时命中拒绝词库/广告模式时按既定优先级放行。
- 分别关闭通用词库、广告检测、LLM，确认所有关联路径均停止。
- LLM 超时、异常、非 JSON 输出时回退默认动作。

## P0：工具 Schema

- 生成全部工具的最终 Schema，递归校验数组均有 `items`。
- 按名称检查批量禁言/踢人的 `user_ids.items.type`。
- 验证一个工具声明变化不会因索引漂移破坏测试。
- 可选 Gemini 冒烟；无密钥或网络时不影响 CI 主结果。

## P1：反刷屏

- 连发 3 张不同图片：频率可统计，但不得按重复 `[图片]` 处罚。
- 相同文字连续发送：仍应触发重复内容策略。
- 图片、文字混发：验证占位符不污染文本重复判断。
- 同用户短片段在 5 秒内拼成违禁词：命中并清空状态。
- 跨用户、跨群、超时、被非文本打断：不得错误拼接。

## P1：Mixin 与命令入口

- 导入并实例化 `Main`，检查每个注册命令依赖的方法存在。
- 覆盖禁言、解禁、踢人、名片、管理员、撤回等核心命令的最小集成调用。
- 新增 Mixin 后核对 `Main` 继承清单及 MRO（左高右低）。
- 新命令别名同时验证 README 列表和 `/help` 输出。

## P2：群管动作与兼容

- 指令、LLM 工具、审核联动、WebUI 远程入口调用同一共享动作。
- 权限不足时返回可读提示，而非裸 OIDB 错误。
- WebUI 操作者绑定 QQ 后，按目标群角色校验权限。
- 撤回超过 2 分钟、历史消息超过 100 条、批量限速时优雅失败。

## 完成标准

- P0 全部进入 CI；P1 随相关模块修改强制运行；P2 可含协议模拟测试。
- 每个修复先提交能复现问题的失败用例，再提交实现。
- 外部服务测试只能补充本地确定性断言，不能替代它。
